### About

I'm a fresher full-stack developer who spent the last year turning what I studied in Information Technology at Lac Hong University into things that actually run in production. Most recently that meant building a leave-management system at BigAppTech; on my own time it's meant going further — an AI-powered learning platform and a hotel management system, both built mostly to see how far I could push a project without a syllabus telling me what comes next.

What I care about most is code that's easy to reason about — layers that don't leak into each other, validation that's actually enforced, tests that catch real bugs before they ship. I'm also happiest at the point where backend logic meets frontend motion, where a well-timed animation makes an interface feel considered instead of just functional.

I'm early in my career and I'd rather be upfront about that than oversell it. I learn fast, I ask when I'm unsure, and I'm looking for a team that will teach me something along the way.
